# CHAT//SURVIVOR

시청자 채팅이 전장에 개입하는 뱀서류 웹 게임의 플레이 가능한 MVP입니다.

## 실행

1. `.env.example`을 복사해 `.env`를 만듭니다.
2. `.env`의 `YOUTUBE_API_KEY`에 새 API 키를 입력합니다.
3. `npm start`를 실행하고 `http://127.0.0.1:4173`을 엽니다.
4. 오른쪽 패널에 현재 방송 중인 YouTube 라이브 URL을 입력합니다.

- 이동: WASD / 방향키 / 모바일 방향 버튼
- 공격: 가장 가까운 적 자동 조준
- 시청자 개입: 오른쪽의 모의 채팅 명령 버튼
- 강화 선택: 카드 클릭 또는 숫자 1~3

YouTube 채팅 명령:

- 지원: `!회복`, `!보급`, `!실드`
- 방해: `!러시`, `!정예`, `!보스`
- 특수 방해: `!암전`, `!둔화`, `!봉인`, `!텔포`, `!지뢰`, `!혼란`
- 레벨업 투표: `!1`, `!2`, `!3`

방해 명령은 혼돈 게이지를 올리며, 100%가 되면 강제 정예 웨이브가 시작됩니다. 모의 채팅 버튼도 함께 사용할 수 있습니다. API 키는 브라우저로 전송되지 않으며 `.env`는 Git에서 제외됩니다.

## 전투 콘텐츠

- 스테이지는 초반 15초부터 점차 길어져 70스테이지에 현재 속도인 45초가 되며, 이후에는 45초로 유지됩니다. 지역은 15스테이지마다 격리 구역 → 폐기물 처리장 → 붉은 연구소 → 공허 관문 → 무한 침식 순서로 바뀌고 이후 순환합니다.
- 적: 추적자, 돌격체, 탱커, 원거리 사수, 분열체, 정예, 스테이지 보스
- 무기: 펄스 라이플, 궤도 드론, 충격파 코어, 테슬라 릴레이, 추적 미사일, 톱날 오라
- 성장: 무기 해금·강화 외에도 연사, 다중 사격, 관통, 방어력, 이동 속도, 자석 범위를 강화할 수 있습니다.
- 무기는 5레벨에 각성하고 30·50·100레벨에 다시 진화합니다. 각성 이후에도 레벨 상한 없이 강화할 수 있으며, 레벨마다 해당 무기의 피해가 45% 증가하고 공격 주기가 4% 감소합니다. 개별 무기의 초월 쿨다운 감소는 최대 72%이며, 시간 가속기까지 합친 최종 쿨다운 감소는 최대 99%로 제한됩니다.
- 전장은 6,000×6,000 크기의 카메라 추적형 월드이며, 우측 상단 미니맵으로 위치와 적 분포를 확인할 수 있습니다.
- 스테이지가 높아질수록 적의 체력은 약 14%, 공격력은 약 11%, 이동 속도는 약 4%씩 누적 증가하며 동시 출현 수도 완만하게 늘어납니다. 일반 적은 최대 320마리까지 유지되고 스테이지 보스전에는 생성량이 절반으로 감소합니다.
- 15의 배수 스테이지에서는 모든 잡몹과 적 탄환이 제거되고 전용 레이드 보스가 등장합니다. 보스는 체력에 따라 3단계로 강화되며 처치 전에는 일반 웨이브가 중단됩니다.
- 레이드 보스 계열: 15스테이지 `심연의 군주`(방사형 탄막), 30스테이지 `시간 포식자`(감속·나선탄), 45스테이지 `군체 여왕`(분열 군단 소환), 60스테이지 `멸망의 눈`(회전 레이저). 이후에는 강화된 계열이 순환합니다.
